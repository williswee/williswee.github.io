About this project

HOW CHIX RUN WAS MADE.

I wanted to make a fun little game with KAPLAY, a free browser game engine. It handles drawing, movement and checking when things bump into each other.

I worked with Codex, an AI coding tool, to build and refine the game through feedback and playtesting. The chicken is drawn from simple shapes, and the sounds are made in your browser.
