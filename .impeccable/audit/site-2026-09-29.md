## Findings addressed

### [P2] Published bookmark targets depended on JavaScript

**Category:** Implementation integrity / accessibility.

**Locations:** `guide.html`, `guide-game.js`; `books.html`, `books-game.js`. A concrete cross-page case was `coaching.html` linking to `guide.html#my-debugging-process`.

Guide's 50 rule IDs and Books' 47 card IDs were previously assigned only when enhancement scripts ran. The document content remained available, but a shared link could not land on the intended rule or book with JavaScript unavailable.

**Fixed:** Those existing IDs are now committed to HTML. Current public slugs are preserved; JavaScript continues to enhance copying, filtering, and focus rather than creating essential targets.

### [P2] Canonical and social-preview metadata was incomplete

**Category:** Implementation integrity.

**Locations:** All indexed page heads; Gratitude's generated head in `scripts/render-gratitude.mjs`.

All 50 indexed documents lacked canonicals, and only Coaching had complete social-preview metadata. Homepage and archive index aliases could be shared inconsistently, while most page links lacked an intentional title, description, and preview image.

**Fixed:** All 50 indexed documents now declare their canonical URL. All 51 documents have social-preview metadata using existing page truth and assets; Coaching retains its dedicated preview image. The not-found page remains `noindex`, is excluded from the sitemap, and has no canonical that would index an error address. Gratitude's generator remains the source of its generated markup.

### [P2] Some scene and preview images lacked async decoding

**Category:** Performance.

**Locations:** The five homepage scene images in `index.html`; archive scenery in `thoughts/index.html`; the project preview in `work.html`.

The homepage eagerly fetches 1,479,204 bytes of artwork. Its download policy is deliberate so artwork is ready during scrolling, but synchronous image decoding could compete with initial rendering.

**Fixed:** Missing `decoding="async"` attributes were added. Existing eager scene loading, first-image priority, optimized artwork, intrinsic dimensions, and established lazy loading are retained. This improves decoding behavior without claiming a measured network-size reduction.

### [P2] Offscreen mobile navigation destinations lacked an arrival cue

**Category:** Responsive design / accessibility.

**Locations:** `reading-nav.js`, `thoughts/reading-room.css`.

At a 390 px phone width, Gratitude could be fully outside the header scrollport with no visible indication that further destinations were available. The active link was not revealed on arrival.

**Fixed:** The active destination is revealed inside the navigation scrollport as the page settles. Restrained drawn chevrons identify available links before or after the visible row. Cue classes update on horizontal scroll and layout changes in one queued animation frame. Manual horizontal exploration and back/forward restoration retain the visitor's chosen position. Delegated keyboard scrolling still initializes before body parsing; without enhancement, navigation wraps in normal document flow.

### Reduced-motion craft correction

**Category:** Accessibility / implementation integrity.

**Locations:** `home-game.css`, `thoughts/reading-room.css`, and interaction feedback that shares these styles.

The homepage had a global `0.01ms` animation/transition override; the reading styles globally removed all transitions. State remained available, so this was not reported as a proven WCAG failure. The approach did not distinguish scene movement from useful feedback.

**Polished:** Reduced-motion behavior is now targeted. Scene movement, spinning dice, and animated scrolling are suppressed deliberately, while useful color, state, and restrained feedback remain understandable. The treatment preserves orientation and control feedback.

## Discovery and delight polish

- **Find an essay:** The Thoughts archive now filters by title or year, retains year groups, announces the current result count, limits Random pick to matching essays, and provides a clear empty state with recovery. Search remains hidden until its handlers are ready; the complete static archive is available without JavaScript.
- **Reading estimates:** Essays show a calm estimated reading duration alongside existing metadata. This helps visitors choose something that fits their available time.
- **Continue reading:** Essays offer actual neighboring entries from the shared chronological manifest before the coaching invitation. First and last entries are handled explicitly; no invented recommendations or dead ends are added.
- **Mobile orientation:** Active-link reveal and decorative overflow cues make the shared reading navigation discoverable. Native links and familiar keyboard behavior remain the foundation.
- **Consistent finishing:** Spacing, control feedback, and reduced-motion handling were refined within the established opaque reading panes and square gold-corner vocabulary.

## Positive findings to preserve

- Zero-build HTML/CSS/JavaScript has no framework, bundler, or runtime package dependency.
- All tracked documents have language, title, description, viewport, header, main, and one primary heading. No static heading hierarchy jumps or duplicate static IDs were found.
- All **1,316** local public link, anchor, and asset references resolve. Authored text was compared with the original source across all 43 essays, 47 books, the Guide, and 63 Gratitude notes; it is unchanged. Every image has alt text and intrinsic dimensions.
- On the opaque `#050c17` reading pane, core text tokens measure **9.47–16.24:1** contrast. Gold, green, and teal each exceed **11:1**. These measurements do not certify every possible composited or transient state.
- Artwork is separate from readable ink surfaces. Responsive panes and font sizes protect long-form content and long titles.
- Books and Gratitude retain accessible random selection, stable links, Escape recovery, nearby floating controls, and readable keyboard-focused entries.
- Newsletter forms load only when useful, keep a direct subscription link, and offer recovery when the provider is unavailable. A cross-origin frame load is not treated as proof of successful signup.
- Coaching retains native POST, validation, explicit provider fallback, error recovery, duplicate-submit protection, and draft retention. Local mocked checks do not confirm provider-side email delivery.
- Article videos use `preload="none"`; below-the-fold images already use lazy loading and responsive source sets where available.
- The sitemap covers all 43 essays. Gratitude output and its sitemap date are generated from approved source notes.

## Detector evidence and false positives

The initial bundled detector output was saved outside the repository at `/tmp/williswee-audit-detector.json`. It reported **degraded regex mode** because HTML parser dependencies were unavailable. Computed styles, selector matching, custom properties, and rendered contrast were not evaluated; its output is not a clean bill of health.

The whole-directory scan included untracked review prototypes and obsolete `style.css`, which no tracked public page loads. Those findings do not describe the shipped visual system. Remaining advisories include documented responsive type variants, intentional neutral shadow values, and legacy inline image corner radii.

The Gratitude “aphoristic cadence” warning is a false positive against approved personal notes. No author copy was changed in response. Muted `#888` captions in older essays still measure 5.53:1 on the reading pane and were not reported as contrast failures.

**Final detector result:** The coordinated final scan covered 58 changed source targets and returned 22 findings: one warning against approved Gratitude prose (false positive) and 21 advisories. The advisories are existing responsive font variants, existing caption/chart/navigation color literals, and legacy image radii. They were reviewed in context and do not identify a blocked task. Parser dependencies remain unavailable, so the scan ran in degraded regex mode and cannot certify computed contrast. Full evidence is in `site-2026-09-29-detector.json`.
