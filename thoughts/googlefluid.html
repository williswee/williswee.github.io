A small experiment with Google Search

Making fluid UI easier to visualize through something we already use.

24 September 2026

After trying TypeSafe’s Jev as a router in one of my projects, I wanted to try it on the frontend too.

Then I came across ShapeShift, an open-source fluid interface by Anish Gupta (@anishfn) on X. I thought it was pretty cool. The interface changes based on what you type.

I wanted to try that idea on something familiar. Google Search felt like a good place to start. It already has custom interfaces for specific searches, which help make the results useful.

So I built a small experiment. As you type a query, a matching interface pops up. ShapeShift’s / menu for discovering tools, and its widgets that respond to what you type, helped shape it.

It’s nowhere near as detailed or polished as Google’s actual UI. But I thought using a service billions of people already know could make fluid UI a little easier to visualize.

You can try it here.

This is an independent experiment, built for fun. It is not affiliated with Google.
